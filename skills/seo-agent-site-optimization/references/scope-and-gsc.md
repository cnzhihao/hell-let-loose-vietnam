# SEO Scope and GSC Data

## Phase 0: establish scope and access

Confirm:

- Target domain and canonical protocol;
- Local project root;
- Exact GSC Property;
- Search type, date range, timezone, country and device filters;
- Local-only work versus authorized public deployment.

Read the project `AGENTS.md`, `README.md`, current SEO/content instructions, relevant routes/data, existing SEO reports, deployment scripts and Git status. Never infer a property from a similar project name. Reuse an existing signed-in browser session; if login is required, ask the user to authenticate without requesting or saving credentials.

## Phase 1: export and verify

In the exact Property:

1. Set the agreed search type, period, timezone and filters;
2. Export the original `.xlsx` without losing period/property identity;
3. Verify it is a real XLSX and keep the original intact;
4. Record path, export time, Property, period, filters and headline metrics;
5. Capture clicks, impressions, CTR, average position, top queries, top pages and non-zero rows.

Use the spreadsheet runtime or workbook library when analysis is needed; do not guess from a filename.

If the report has no data, do not manufacture recommendations. Perform only site-readiness checks, ask what can be diagnosed without search data and set D+7/D+14 observation dates.

## Phase 2: upload and session

1. Open the user’s SEO Agent site-report area, normally `https://seo.web.cafe/mysite/`;
2. Upload the exact XLSX;
3. Compare the displayed domain/property character-for-character with the target before confirming;
4. Open the chat area, normally `https://seo.web.cafe/chat/`;
5. Join the existing session when present;
6. If UI errors occur, retry only a bounded number of times and record the error;
7. Do not create duplicate reports, sessions or accounts to work around an unclear state.
