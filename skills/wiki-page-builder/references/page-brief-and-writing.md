# Wiki Page Brief and Writing

## Preflight

Read `README.md`, `AGENTS.md`, the project’s detailed Wiki-page production plan, relevant keyword materials, page matrix, asset inventory, target page data, route, shared components, styles and `git status --short --branch`. Confirm existing content, sources, reusable visuals, unverified facts and user changes before editing.

## Page brief

Write this before prose:

```text
Keyword / player question:
The task this page helps complete:
What the player has at the start:
What the player should see at the end:
First click / key:
Next step after success:
Route:
Evidence state:
```

The page must answer:

1. What do I click or press first?
2. Where exactly do I look?
3. What result should I see?
4. When do I continue?
5. What should I check first if it fails?

## Fact boundary

Prefer official website, official storefront, official Wiki and official YouTube; use Steam Community, Reddit, reliable media and player videos only as supplemental evidence.

- A player video proves that player used a route, layout or workaround; it does not alone prove an official mechanism, fixed coordinate, recipe, key or version rule;
- Label community footage `YouTube community gameplay`, `player example` or equivalent;
- Without a complete transcript, describe only title, description, chapters or visible frames actually checked;
- Mark uncertain shortcuts, prices, recipes, version differences, Mod paths, Seeds and platform claims as pending;
- Cross-check important facts and date dynamic facts.

## Action chain

Compress the page into 4–6 verbs before expanding it:

```text
Unlock / obtain → find entry → click / press → read interface
→ complete minimum action → verify result → return to main loop → advanced use
```

Example for a Map guide:

```text
Research → Map → expand map → use Minimap → return to factory → build
```

## Recommended article structure

```text
H1: [object] Guide: [final player action]
One-sentence summary
Short answer
Overall flow

H2: Unlock / obtain [object]
H2: Find and open [object]
H2: Complete the first task
H2: Return to the game loop
H2: Advanced: Seeds / Mods / special versions
H2: FAQ
Sources & Attribution
Related pages
```

Each core H2 solves one action. Write instructions for the player, not research-process language. Put evidence in captions and Sources, while the body explains actions, results and troubleshooting.
