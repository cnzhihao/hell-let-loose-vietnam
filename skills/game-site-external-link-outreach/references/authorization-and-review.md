# 外部授权、状态核验与复盘

本文件处理外部动作的授权边界、执行后的证据和后续复盘。准备材料不等于获得发布权限。

## 1. 动作权限表

| 动作 | 未明确授权时 |
|---|---|
| 搜索公开规则、公开入口和相关页面 | 可以只读执行 |
| 形成候选清单、评分、文章大纲、邮件或回答草稿 | 可以本地准备 |
| 打开提交页、填写表单但不提交 | 只在不改变外部状态且无敏感数据时进行 |
| 发布文章、提交目录、发送邮件/私信、发帖/评论 | 必须先确认具体渠道、正文、目标 URL 和动作 |
| 创建账号、购买链接、付费投放、修改第三方 Wiki/数据库 | 必须单独确认，不能由“做外链”推断 |

授权前应向用户展示：渠道和公开入口、收件人/账号上下文、最终正文、本站目标 URL、预期状态、可能的公开性/审核风险和将产生的状态变化。若授权后改变收件人、正文、目标页面或平台，重新确认。

## 2. 一次一个动作，一次立即核验

1. 只使用已核验的公开收件人或入口；
2. 执行一个已授权动作；
3. 立即检查页面返回、公开 URL、邮件“已发送”状态或审核状态；
4. 保存 URL、状态页、截图或其他可复查证据；
5. 失败、权限不足、页面不可见或状态不明时停止并如实记录，不把按钮点击写成成功外链。

不要在一次授权下顺手扩展到其他平台、其他页面或其他联系人；每个对外动作都要能回到用户确认的范围。

## 3. 状态词的准确含义

使用明确状态，不混用：

- 草稿：只存在本地，未对外提交；
- 已发送：邮件/私信已被发送，但没有证明对方阅读或引用；
- Pending：已提交，正在审核或等待平台处理；
- Approved：平台或编辑确认接受，但仍需打开公开页面核验；
- 公开：能打开公开 URL，但尚未完成链接属性或引荐验证；
- 已核验：公开 URL、页面内容、链接属性和必要的证据已复查；
- 拒绝：明确被平台、编辑或收件人拒绝；
- 阻塞：缺权限、无公开入口、规则不允许或状态无法验证。

“公开 URL”不自动等于 dofollow；“已核验链接”不自动等于带来访问、提高排名或被搜索引擎收录。

## 4. 记录和复盘

在现有外链文档中追加，不覆盖历史记录。每条记录至少包含渠道/来源 URL、目标 URL、形式、状态、锚文本或描述、链接属性、发送/提交/公开时间及时区、事实来源、结果证据、GA4 引荐观察和后续动作。具体 Markdown 模板见 [templates-and-scorecard.md](templates-and-scorecard.md)。

以发布或提交日为起点：

- 第 7 天：检查是否仍在线、是否有回复、是否有初步引荐会话；
- 第 14 天：检查页面状态、链接属性、引荐质量和是否需要维护；
- 第 30 天：仅在审核周期较长或内容价值值得长期观察时增加。

GA4 referral、engaged session、GSC/Ahrefs 观察都要注明时间范围和数据来源。实时测试访问、邮件客户端点击或人工打开页面不能写成长期搜索流量。

## 5. 对外交付格式

一次研究或执行完成后，按任务范围汇报：

1. 结论和渠道选择原因；
2. 候选、评分、状态和排除原因；
3. 内容/沟通稿及其目标页面；
4. 授权状态；
5. 规则、公开 URL、发送记录或阻塞证据；
6. 当前外链状态及是否真的算公开 backlink；
7. 记录改动和 7/14/30 天复盘点；
8. 一个最小、相关、可验证的下一步。
