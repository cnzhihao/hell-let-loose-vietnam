# 外链目标、资产矩阵与渠道评分

本文件用于外链研究和候选优先级判断。它不授予发布、联系、提交表单或创建账号的权限；这些动作必须遵守 `authorization-and-review.md`。

## 1. 目标与基线

先确定本轮真正要解决的结果：

- 让真实玩家发现站点并产生引荐访问；
- 让创作者、媒体或 Newsletter 在相关内容中获得可选补充资料；
- 询问官方社区资源列表是否适合收录；
- 向游戏数据库贡献准确的事实资料；
- 只做渠道研究和候选清单。

记录 GSC、GA4、Ahrefs 或其他工具的统计日期、地区、设备和时间口径。可疑历史外链单独记录为未知，不因一次第三方快照断定受罚，也不要为了“清零”批量 disavow。

## 2. 内容资产 → 外部语境矩阵

外链候选必须先绑定一个能独立解决问题的站内深层页：

| 字段 | 要回答的问题 |
|---|---|
| 目标页面 | 外部读者点击后能完成或理解什么？ |
| 玩家问题/关键词 | 外部页面中的哪个真实语境与它匹配？ |
| 内容形式 | 文章、回答、视频说明、资源列表还是资料库条目？ |
| 证据 | 事实来自哪些官方页、更新说明或已标注的社区素材？ |
| 主要链接 | 是否只需要一个最相关的本站链接？ |
| 维护价值 | 页面是否会随版本更新而继续有用？ |

优先选择资源、建筑、机制、地图、更新和新手任务等具体问题页；只有当外部语境确实是综合入门问题时才链接新手页或首页。没有可靠页面、来源或版本边界时，先回到内容建设，不先做外链。

## 3. 渠道发现与核验

重要候选至少核验以下内容：

1. 页面真实可访问，且有真实游戏受众；
2. 平台官方规则是否允许投稿、外部资源或资料库贡献；
3. 入口是公开邮箱、投稿表单、创作者公开联系方式还是不存在；
4. 当前项目账号是否具备所需权限，例如购买正式版、登录或回复资格；
5. 最终结果能否用公开 URL、审核状态、页面 DOM 或“邮件已发送”状态验证。

搜索结果和经验文章只用于发现线索，不是渠道规则的最终证据。没有公开入口、不清楚读者是谁或只能靠猜测建立联系时，记录为阻塞或排除，不绕过限制。

## 4. 评分和决策

对可行候选按 0–2 分评估以下五项，总分 10 分：

- 真实受众：是否能确认有游戏玩家或专业读者；
- 主题相关性：页面问题是否直接匹配目标 Wiki 页；
- 编辑可信度：是否有编辑、社区或数据库维护规则；
- 权限可行性：是否有合法公开入口且当前权限足够；
- 可测量性：是否有公开 URL、状态页或可区分的引荐数据。

解释总分时使用以下区间：

| 总分 | 决策 |
|---:|---|
| 8–10 | 优先执行，但仍需单次明确授权 |
| 6–7 | 小规模测试，先做一个动作 |
| 4–5 | 只保留为备选，除非存在强场景 |
| 0–3 | 排除 |

硬性排除优先于总分：付费买链、主要销售 SEO 外链、没有真实页面或读者、需要猜邮箱、需要绕过登录、要求链接交换或批量自动化，均不执行。

## 5. 研究结果的最小记录

每个候选至少写清：渠道名称、规则/入口 URL、目标读者、匹配的站内页、评分、当前权限、预期状态、风险、是否需要用户授权和排除原因。把“值得研究”与“值得执行”分开，避免高分指标替代真实读者价值。
