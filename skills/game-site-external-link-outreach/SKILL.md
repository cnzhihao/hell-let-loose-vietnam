# Game Site External Link Outreach

把外链工作做成可复查的“内容资产 → 相关外部语境 → 授权动作 → 状态核验 → 引荐复盘”链路。目标是让真实玩家发现并信任一个持续维护的游戏 Wiki，不是堆链接数量或购买所谓高质量外链。

## 使用边界

适用于：

- 查找游戏 Wiki、攻略、媒体、创作者、官方资源列表、社区和资料库的相关机会；
- 规划原创文章、社区回答、资源列表询问、创作者/媒体联系或数据库贡献；
- 准备外展稿、渠道评分卡、链接记录和 7/14/30 天复盘；
- 核验公开 URL、审核状态、链接属性和 GA4 引荐。

如果任务只是研究关键词、核验游戏事实或生产站内页面，使用对应的研究、建站或 Wiki Skill；只有涉及外部渠道和引荐关系时才启用本 Skill。

## 硬边界

- 先做只读研究和草稿，不因用户说“找外链”就自动发帖、发邮件、提交表单或创建账号。
- 发布文章、社区回答、目录条目、邮件、私信和评论都代表用户对外沟通；执行前必须得到对具体渠道、目标页面、正文和动作的明确授权。
- 不买 guest post、link insertion、PBN、包月建链或链接交换；不自动评论、批量私信、猜邮箱、绕过登录、冒充官方或灌录目录。
- 不把草稿、已发送、Pending、公开 URL、已核验链接和引荐流量混写；“有链接”也不等于 dofollow、排名提升或长期访问。
- 不把搜索摘要、实时测试访问、Gmail 点击或提交按钮结果写成收录、排名或长期流量。

## 主工作流

### 1. 读取项目状态

先只读检查项目根目录的 `README.md`、`AGENTS.md`、当前外链记录、关键词素材、页面矩阵和来源清单；若使用图片，再读取素材清单与 manifest。检查 `git status --short --branch`，保留已有改动，编辑 Markdown 使用 `apply_patch`。

如果用户要求查看生财有术手册，遵守项目 AGENTS：通过生财 MCP 的活动搜索/目录/正文链路读取，不用通用搜索替代；读取本身不包含提交作业或站内互动授权。

### 2. 明确本轮结果

先区分本轮是：渠道研究、读者引荐、创作者/媒体引用、官方资源收录、资料库事实贡献，还是已经授权的具体发布/联系动作。记录 GSC、GA4 或其他外链工具的统计日期和口径；未知历史外链单独标为未知，不因单次快照批量清理。

### 3. 选择内容资产和外部语境

优先选择能独立解决玩家问题的深层页，不让所有渠道都指向首页。对每个候选记录目标页面、玩家问题、内容形式、事实来源、一个主链接和持续维护价值。没有可靠页面承接时，先补内容，不先找链接。

### 4. 发现、核验和评分渠道

查平台官方规则、真实入口、近期相关页面和必要的案例；不要只凭搜索摘要或一篇经验文章下结论。按真实受众、主题相关性、编辑可信度、权限可行性和可测量性各 0–2 分，总分 10 分；付费买链、SEO 站群、无真实读者、猜联系方式或需要绕过权限时直接排除。

### 5. 产出适配渠道的内容

文章、回答或条目即使删掉本站链接也应对外部读者有完整价值。使用独立组织的正文、官方来源、版本边界和必要的社区归因；通常只放一个最相关的深层链接，不复制同一文章跨平台发布，不把独立站写成官方站。

### 6. 授权、执行和现场核验

授权前只提交候选、风险、最终正文、目标页面、收件人/入口和预期状态供确认。授权后遵循“一次一个动作、立即一次核验”：只使用已核验入口，执行后保存公开 URL、审核状态、邮件发送状态或页面证据；失败、权限不足和状态不明都如实记录。

### 7. 记录和复盘

在现有外链文档中追加记录，不覆盖历史事实。至少记录渠道/来源 URL、目标 URL、形式、状态、锚文本或描述、链接属性、时间及时区、事实来源、结果证据和后续检查点。以提交或公开日期为起点检查第 7 天和第 14 天，平台周期较长时增加第 30 天；不要把实时访问写成长期引荐流量。

## 标准交付

按任务范围交付以下适用部分：

1. 结论：最值得做的渠道和原因；
2. 候选清单：读者、目标页面、评分、状态和排除原因；
3. 内容或沟通稿：文章大纲、邮件/私信、社区回答或目录描述；
4. 授权状态：待确认、已确认或已执行；
5. 证据：规则页、公开 URL、状态页、发送记录或阻塞证据；
6. 外链状态：草稿、已发送、Pending、公开或已核验，并说明是否真的算公开 backlink；
7. 记录和复盘：文档改动、7/14/30 天检查点及 GA4/GSC 后续；
8. 下一步最小动作：只给一个相关且可验证的动作。

当用户只要求“找渠道/规划”时，停在研究和草稿阶段；只有用户明确确认具体渠道、具体内容和具体动作，才执行对外操作。
