## Beginner-guide action chain

1. Open the official `Getting Started` tutorial.
2. Complete it before joining the first public match; the official material says it is optional, but this site recommends it for the first run.
3. Join a squad and communicate what you are doing.
4. Identify the active objective using the current in-game map and squad communication.
5. Leave Squad Leader and Commander until their required tutorials are complete.
6. Return to the Wiki for mode rules or verified role families after the first match.

The exact menu path beyond the official tutorial label and the documented `Esc` skip control is intentionally not invented. Platform-specific keybinds require a separate current-build verification pass.
