# Docs 目录

这里保存某个具体游戏项目的研究和交付资料，不把它们硬编码进框架层。

- `keywords.json`：关键词、搜索意图和页面矩阵的机器可读起点；
- `keyword-materials.md`：逐词来源、事实、证据状态和待复核项；
- `page-matrix.md`：页面类型、路径、优先级和内部链接规划；
- `reference-objects.md`：参考网站的结构研究，不复制内容或品牌；
- `素材清单.md`：图片/视频关键帧的来源、用途、归属和使用边界。

模板中的示例只用于说明字段，不代表任何具体游戏事实。研究完成后再将条目写入 `src/content/`，不要让搜索摘要直接成为页面内容。
